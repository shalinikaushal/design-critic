# Example input: e-commerce product page and cart

**Artifacts (illustrative, described in text so the example is self-contained):**

- `product-detail` (390x1400): full-width product photo, product name, price, a row of unselected size chips (S to XL), a green Add to bag button, and a description accordion. No delivery or returns text.
- `cart` (390x844): line items with thumbnail, size, colour, a small outlined quantity stepper and a remove link; an order summary with Subtotal and "Shipping: calculated at next step"; a dark green Checkout button.

**Platform:** mobile web. **Audience:** shoppers browsing on phones.

**Goals:** increase add-to-bag rate; reduce cart abandonment.

**Request:** "Why might people be dropping out between product page and checkout?"
