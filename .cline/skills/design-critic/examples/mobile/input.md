# Example input: mobile habit tracker (mostly good design)

This example exists to show that the skill reports few findings when a design is sound.

**Artifacts (illustrative, described in text so the example is self-contained):**

- `onboard-1` (412x915): a short headline, one illustration, and one large "Get started" button.
- `onboard-2` (412x915): a list of six habit suggestions with icons, a 08:00 time picker, and one "Continue" button.
- `home` (412x915): a large "Today" heading, a habit card with a checkbox, and a streak counter in large type.

**Journey:** Get started, choose a habit and a time, mark it done on the home screen.

**Platform:** Android. **Audience:** adults building daily habits.

**Goals:** users create their first habit during onboarding; users return the next day.
